# MyContact (تماس من)

اپلیکیشن اندروید که فایل `MyContact.html` (نسخه‌ی WebRTC صوتی/تصویری/چت) را داخل یک WebView اجرا می‌کند.

## ساختار پروژه
- `app/src/main/assets/MyContact.html` — همان فایل HTML شما، بدون هیچ تغییری در ظاهر یا امکانات.
- `app/src/main/java/com/mycontact/app/MainActivity.java` — WebView را بالا می‌آورد و مجوزهای دوربین/میکروفن را برای تماس صوتی و تصویری مدیریت می‌کند.
- `app/src/main/AndroidManifest.xml` — مجوزهای CAMERA، RECORD_AUDIO، INTERNET.
- `.github/workflows/build-apk.yml` — هر بار که پوش کنید، خودش روی سرورهای گیت‌هاب APK را می‌سازد (نیازی به نصب اندروید استودیو نیست).

## مراحل گرفتن APK

1. تمام فایل‌های این پوشه را داخل ریپوی خالی `MyContact` خودتان کپی/پوش کنید:
   ```bash
   cd MyContact          # ریپوی خالی که از قبل کلون کرده‌اید
   # فایل‌های این پوشه را داخلش کپی کنید، سپس:
   git add .
   git commit -m "WebView app wrapping MyContact.html"
   git push
   ```
2. در گیت‌هاب به تب **Actions** ریپو بروید؛ به محض پوش، ورک‌فلو «Build APK» خودکار اجرا می‌شود (چند دقیقه طول می‌کشد).
3. وقتی اجرا سبز شد، روی همان ران کلیک کنید و پایین صفحه بخش **Artifacts** یک فایل به اسم `MyContact-debug-apk` می‌بینید؛ دانلودش کنید — یک ZIP است که `app-debug.apk` داخلش است.
4. فایل APK را روی گوشی بریزید و نصب کنید (لازم است «نصب از منابع ناشناس» را برای آن اپ/مرورگر فعال کنید، چون امضای دیباگ است نه امضای Play Store).

## نکات مهم
- این APK با **کلید دیباگ پیش‌فرض** امضا شده؛ برای استفاده‌ی شخصی بین شما و دوستتان کاملاً کافی است. اگر بعداً خواستید در جای دیگری منتشرش کنید، باید یک keystore واقعی بسازید و signingConfig را در `app/build.gradle` عوض کنید.
- دامنه/کلید Metered شما طبق چیزی که قبلاً گفته بودید از قبل داخل خودِ `MyContact.html` به‌صورت پیش‌فرض ست شده — چیزی در این پروژه‌ی اندرویدی به آن اضافه نشده.
- اگر دوربین ندارید یا نمی‌خواهید فعلاً تماس تصویری تست کنید، مشکلی نیست: مجوزها فقط وقتی از کاربر پرسیده می‌شوند که صفحه واقعاً `getUserMedia` صدا بزند (یعنی وقتی روی دکمه‌ی تماس صوتی/تصویری بزنید).
- برای اینکه چرخش صفحه در وسط تماس، اتصال WebRTC را قطع نکند، اکتیویتی هنگام چرخش دوباره ساخته نمی‌شود (`configChanges` در Manifest).
